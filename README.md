# Python 练习与实用小工具集

个人日常编写的 Python 趣味脚本、基础编程练习与实用配置文件合集。

## 文件列表

- **`rotating_hexagon_ball.py`**：旋转六边形内的弹球物理碰撞模拟（包含重力、弹性碰撞与旋转边界计算）。
- **`出租车付费.py` / `分支结构程序实例：登录程序代码.py` / `计算三角形面积.py` / `计算圆的面积和周长.py`**：Python 基础语法与计算练习脚本。
- **`EdgeSmartDoH_linuxdo.mobileconfig`**：iOS / macOS 加密 DNS（DoH）描述文件配置。
